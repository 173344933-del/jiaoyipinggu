# 交易模型诊断室 · 二级市场情绪样本库

> 对标芝士财富，但卖的不是个股数据，而是**大师的思考方式**。输入股票代码，每位大师的 agent 用自己的交易模型给出诊断：实盘级大师检索真实历史判断与持仓，模型抽象级大师给出该模型下的检查清单。
> 定价设计：免费版（3 位 agent 每日 5 次）/ 专业版 ¥199/年（全部 agent 无限次 + 13F 披露即推 + 每日两次大师动态推送 + 持仓接入 + 报告导出）。

## 系统组成

| 模块 | 文件 | 说明 |
|---|---|---|
| 情绪样本库网站 | `index.html` + `library.js` + `masters.js` + `stocks.js` | 46 标的 1444 条带日期判断记录；10 位大师 agent；多大师诊断（支持代码/拼音/中文名输入，约130个代码映射）；诊断报告导出（Markdown/打印PDF）；大师动态页（feed.json 实时内容）；产品与定价页 |
| 13F 采集器 | `fetch_13f.py` | SEC EDGAR 官方源，17 家机构（德鲁肯米勒/巴菲特/桥水/高瓴/景林/李录/Klarman 等），自动按 CUSIP 合并联合申报的多 manager 子表 |
| 双源校验 | `cross_validate.py` | vs GitHub `holdingsintel/holdingsintel-open-data`，同 accession 比对解析结果（曾抓出伯克希尔合并 bug） |
| 资讯采集器 | `collector.py` | 新浪全球/国内快讯 + 雪球热股 + 猫笔刀 RSS（多镜像）+ 人工收件箱；自动分类与大师提及检测 |
| 数据目录 | `data/` | 13f.json / validation.json / feed.json / inbox（人工导入） |
| 预览服务 | `server.js` | `npm run dev` 后访问 http://localhost:7100/ |

## 数据源与数据级别（诚实标注）

- **实盘语料级**：刘备教授——知识星球 2019-2026 七年全量语料 + 真实持仓记录（本库含完整时间线）。
- **实盘13F级**：德鲁肯米勒、巴菲特/芒格、达里奥、Burry、李录、Klarman——SEC EDGAR 原始文件，滞后 ≤45 天，仅覆盖美股多头。
- **模型抽象级**：冯柳（高毅）、猫笔刀、段永平、但斌/林园——公开言论整理的检查清单，**不代表其本人观点**。
- 资讯源：新浪财经（公开接口）、雪球热股（Cookie 流程）、猫笔刀第三方备份站（非官方，源站间歇不可达，已做多镜像兜底）、人工收件箱（封闭源导入）。

## 运行

```bash
cd 情绪样本库
python3 fetch_13f.py        # 更新 13F（季度）
python3 cross_validate.py   # 双源校验（季度，需先下载 GitHub 参考 CSV 到 data/）
python3 collector.py        # 采集资讯（每日两次由自动化任务执行）
npm run dev                 # 本地预览 :7100
```

## 已接入的自动化（每日财经看板）

- **大师动态**：每交易日 07:57 / 18:17 自动采集 + 13F 快照 + 校验状态行，投递到看板 Widget。
- **本地盯盘系统**（不在本仓库）：教授持仓样本与个人持仓的卖点信号监控+桌面提醒，均为本地私有部署。
- **13F 披露即推**（`watch_13f.py`）：每 6 小时监测 8 家核心机构，新季度披露时自动刷新并桌面推送新进/清仓摘要。

## 已知局限

- 13F 为季度快照、滞后 ≤45 天，不含非美资产、期权空头与期内交易。
- 见闻/金十/财联社 API 有反爬，未接入；雪球长文接口已失效，仅热股榜可用。
- 猫笔刀备份站为非官方渠道且稳定性差，重要内容建议同时走 `data/inbox/` 人工导入（格式：`日期｜来源｜内容`）。
- 双源校验参考集滞后一个季度（GitHub 集更新至 2026-Q2）。

## 合规

全部数据来自公开渠道；语料版权归原作者「刘备教授」；本库仅为研究整理，不构成投资建议。
